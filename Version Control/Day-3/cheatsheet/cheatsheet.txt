Push repository to github:

Remote repository :- 
Remote repository is a version of your repository that is hosted somewhere else (for example, on a server or a service such as GitHub, GitLab, or Bitbucket).
It allows multiple people or machines to share and synchronize code.

1. Create a repository on GitHub

Go to:

GitHub

Create a new repository and copy its URL 

2. Initialize Git (if not already initialized)
git init

3. Add and commit your files
git add .
git commit -m "Initial commit"

4. Add the GitHub repository as a remote

Using HTTPS:

git remote add origin https://github.com/<username>/<repository>.git


5. Push to GitHub

If your branch is main:

git branch -M main
git push -u origin main

If your branch is master:

git push -u origin master

6. Verify the remote
git remote -v


Open a pull request:

To open a Pull Request (PR) on GitHub after pushing your branch:

Push your branch to GitHub:
git push -u origin <branch-name>
Go to your repository on GitHub.

GitHub will often show a "Compare & pull request" button after you push a branch. Click it.
Review:
Base branch: usually main
Compare branch: your feature branch

Enter:
A clear title
A description of the changes
Click Create pull request.
