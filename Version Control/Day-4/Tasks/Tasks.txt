Git rebase Vs Git merge 

Git rebase : This command used to integrate changes form one branch to another by rewriting the commit history.

Git merge : This command used to combines independent lines of development from a source branch into your current target branch.

commands : git rebase, git merge.

Git reset : This command moves the current branch to a different commit. Depending on the option we use, it can also unstage changes or discard them.

Command : Git reset.

Git revert : It is used to undo the changes introduced by a commit by creating a new commit. Unlike 'git reset', it does not rewrite history, making it the preferred option for commits that have already been pushed to a shared repository.

Command : Git revert.
